# 🚗 BMW Sales Analysis Dashboard

## 📊 Project Overview

The **BMW Sales Analysis Dashboard** is a data analytics project created to analyze BMW vehicle sales and understand important business trends.

The dashboard provides an interactive view of **sales performance, vehicle models, regions, fuel types, transmission types, and other key sales factors**.

The main goal of this project is to transform raw sales data into meaningful insights that can help understand **sales trends, customer preferences, and overall business performance**.

---

## 🎯 Project Objectives

* Analyze overall BMW sales performance.
* Identify the best-performing BMW models.
* Analyze sales based on different regions.
* Understand customer preferences.
* Compare sales across different fuel types.
* Analyze manual and automatic transmission preferences.
* Identify important sales trends.
* Create an interactive dashboard for easy decision-making.

## 🧮 DAX & Calculations

DAX measures were created to calculate important business metrics such as:

```DAX
Total Sales = SUM(Sales[Sales_Amount])
```

```DAX
Total Vehicles = COUNTROWS(Sales)
```

```DAX
Average Sales = AVERAGE(Sales[Sales_Amount])
```
